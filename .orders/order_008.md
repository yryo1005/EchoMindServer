# Order 008

## ユーザーからの指示（原文）

アカウント登録機能を追加しようかな
デバック用の今のデータをAdminで，メアドとパスワードでログインする感じで
iPhoneのアプリではログインするだけで，録音する機能，検索をリクエストする機能，過去の会話履歴を聞く機能を使える状態にしたい

## 指示の解釈

EchoMindサーバーにアカウント登録・ログイン機能(メールアドレス+パスワード)を追加する．

1. ユーザーはメールアドレスとパスワードでアカウント登録・ログインできる．
2. ログインするとアクセストークンが発行され，以降のAPI呼び出し(録音アップロード，QA検索，過去の会話履歴の閲覧)はこのトークンで認可される．
3. 既存のデバッグ用データ(これまでの動作確認で蓄積した会話・人物データ)は，特定のアカウント(Admin)に帰属させる．
4. iPhoneアプリ(本タスクでは実装対象外)は，ログイン後にこのトークンを用いて「録音アップロード」「QA検索」「過去の会話履歴の閲覧」の3機能を利用できる状態にする．本タスクではiPhoneアプリ自体は実装しないが，サーバー側はこれらの機能をトークン認可付きで提供できる状態にする．

データの分離方針として，会話(Conversation)・人物(Person)はアカウント(User)に紐づけ，QA検索・会話一覧・音声配信は認証済みの自分のアカウントのデータのみを対象とする．

パスワードは平文保存せず，ハッシュ化(bcrypt)して保存する．認可にはJWT(Bearer Token)を使用する．既存データのAdminアカウントへの帰属付けは，ユーザー自身が登録したアカウントに対して一度だけ実行する移行スクリプトで行う(パスワードをAIエディタが直接扱わないようにするため)．
