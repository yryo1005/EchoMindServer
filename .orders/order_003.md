# Order 003

## ユーザーからの指示（原文）

着手して良いですが，ベンチマークと後に実装するサーバーのプログラムを違うディレクトリに配置してください

## 指示の解釈

Order 002で提示したベンチマーク計画の実施を承認する．ただし，ベンチマーク用プログラム（モデル選定のための評価コード）と，選定後に実装するEchoMindサーバー本体のプログラムは，明確に別ディレクトリへ配置することを指示している．

これに基づき，以下のディレクトリ分離方針を採る．
- ベンチマーク: `programs/ex001_model_benchmark/`（`@.ai/ai-dev-kit/machine_learning.md` の実験ディレクトリ命名規則に従う）
- サーバー本体: `programs/server/`（ベンチマークで選定したモデルを用いて実装する，実験ディレクトリの通し番号規則は適用しない）

両者は依存ライブラリが重複する部分が多いため，Python仮想環境 `.venv_ml` は共通のものを使用し，プログラムの配置ディレクトリのみを分離する．
